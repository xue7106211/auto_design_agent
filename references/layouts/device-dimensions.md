# 设备尺寸表

本文档定义各目标设备的画布尺寸和基础参数。

> **负责人**：一飞 + 老唐共同维护
> 以下数值作为当前主链路的执行基线使用；如小米设计规范或 UI Kit 更新，应同步校正本表。
> **Kim 修改建议**：基于 Figma「绑定新 Token」适配规则页 + 应用框架页 + UI Kit 断点规则实测补充。

## 断点间距

各栏内部 padding 根据该栏自身宽度（w）按以下断点判定。应用全屏、分屏、小窗共用同一套规则。

| 断点 | 间距（左右 padding） |
|------|-----------------|
| w ≤ 420 | 12dp |
| 420 < w ≤ 640 | 20dp |
| 640 < w ≤ 800 | 28dp |
| 800 < w ≤ 1100 | 56dp |
| 1100 < w | 56dp + Fill（内容区域 max 988dp，居中展示，两侧边距 Fill） |

> 当容器宽度 > 1100dp 时：内容区域最大宽度 = 988dp（容器 1100 − 左侧间距 56 − 右侧间距 56），不再拉伸，居中展示，两侧边距 Fill。

> 所有 N 栏在显示悬浮侧边栏时，N 栏内部左侧会产生 6dp 的 padding（由组件自身携带）。

## 栏内部结构尺寸

### N 栏侧边栏（NLC / NC 模式）

NLC / NC 模式下的 N 栏为悬浮卡片式侧边栏，内部分层结构如下：

| 层级 | 名称 | 宽度 | 说明 |
|------|------|------|------|
| 外壳 | 侧边栏 | 272dp | N 栏总宽度 |
| 卡片 | 板子材质层 | 260dp | 左偏移 12dp，上偏移 6dp；带圆角背景 |
| 内容 | 导航栏尺寸/形态 | 260dp | 与卡片同宽 |
| 菜单项 | 导航组件_原子 / 菜单内容_原子 | 236dp | 卡片内左偏移 12dp |

菜单项详细规格：

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 菜单内容_原子 | 236 × 44dp | 单行菜单项 |
| 菜单图标 | 28 × 28dp | 左偏移 12dp，上偏移 8dp |
| 标题文字 | 172 × 21dp | 左偏移 52dp（12 + 28图标 + 12间距） |
| 分割线容器 | 236 × 20dp | 包含 0.5dp 高分割线 |
| 分割线 | 212 × 0.5dp | 左偏移 12dp |
| 分组标题（MenuContentAtoms） | 236 × 36dp | 分组分隔标题 |
| 底部悬浮区（Overlay-Showcase） | 236 × 100dp | 底部 BottomBar 悬浮区 |

NLC 收起态：N 栏总宽度缩至 88dp，仅显示图标，隐藏文字和卡片背景。

### L 栏侧边栏（LC 模式）

LC 模式下的 L 栏同为卡片式面板，但宽度更大：

| 层级 | 名称 | Pad 横屏 | Pad 竖屏 | Fold 内横 | Fold 内竖 |
|------|------|---------|---------|----------|----------|
| 外壳 | 侧边栏 | 440dp | 440dp | 353dp | 283dp |
| 卡片 | 板子材质层 | 428dp | 428dp | 341dp | 271dp |
| 偏移 | 左/上 | 12dp / 6dp | 12dp / 6dp | 12dp / 6dp | 12dp / 6dp |

L 栏内部可承载：大标题 NavigationBar + 搜索栏 + 标签栏（SelectableChip） + 列表内容 + 底部 Fab。

### Fold 内屏分栏补充

Fold 内屏横屏 LC 模式存在两种比例：

| 比例 | L 栏 | C 栏 | 适用场景 |
|------|------|------|---------|
| 0.4:0.6 | 353dp | 535dp | 设置、录音、笔记等常规 LC |
| 0.5:0.5 | 444dp | 444dp | 电话（拨号盘展开/收起） |

## 基本对齐方式

画面内控件从上到下依次排列。底部导航栏、Fab 等以画面底部为基准对齐。各区域宽度变化时，控件宽度自适应填充。各控件内部自带左右 padding。

Fold 和 Pad 的所有栏内容从状态栏下方开始排列，各栏内容与状态栏之间需要 6dp 的 padding。

| 控件 | 对齐方式 |
|------|---------|
| 状态栏 | 顶部对齐 |
| 顶部导航（标题栏 / 顶部导航栏） | 顶部对齐 |
| 侧边栏 | 左对齐 |
| 搜索栏 | 顶部对齐 |
| 标签栏 | 顶部对齐 |
| 底部导航栏 | 底部对齐 |
| Fab | 底部右下角对齐 |
| 输入框 | 底部对齐 |

手机 和 Fold 外屏 均直接使用基本对齐方式。

## 横竖屏旋转规则（Pad / Fold 通用）

NLC 与 NC 框架均适用以下规则：

1. **展开态映射**：横屏展开态 ↔ 竖屏展开态，收起态 ↔ 收起态
2. **独立历史记录**：横竖屏各自记录用户干预后的侧边栏状态
3. **状态循环**：横屏收起 →❶ 竖屏展开 →❷ 竖屏收起 →❸ 横屏展开 →❹ 横屏收起
4. **禁止旋转出模态导航**：旋转不能触发导航模态切换


## 浮层规格

浮窗 / 抽屉 / 弹窗 / 菜单的尺寸、位置、结构、内边距、遮罩。浮层不进入 `layoutType` 判定，覆盖在主布局之上。

### 设备对应关系

同一业务场景在不同设备上可能切换浮层形态。

| 小屏形态 | 适用设备 | 大屏形态 | 适用设备 |
|---------|---------|---------|---------|
| 抽屉 DrawerWindow | 手机、折叠屏外屏 | 浮窗 FloatingWindow | 折叠屏内屏、Pad |

### 容器背景色与遮罩（通用）

容器背景：

| 内容形态 | Token |
|---------|-------|
| 有卡片 / 套卡列表（灰底） | `背景色/surface_low` |
| 无卡片 / 纯白（白底） | `背景色/surface` |

遮罩：`遮罩色/mask`（`#000000`）20%，与本文档「遮罩定义」小节一致。

### 浮窗 FloatingWindow

适用设备：Pad、折叠屏内屏；手机端不使用。

| 维度 | 值 |
|------|-----|
| 宽度 | 固定 **546dp** |
| 高度（横屏） | 屏幕高度 × **80%** |
| 高度（竖屏） | 固定 **636dp** |

- 位置：左右居中、上下居中（以屏幕整体几何中心为基准，不扣除状态栏 / 虚拟键 / 小白条）
- 结构：浮窗窗口（容器壳）+ 浮窗_面板（背景）+ 浮窗_标题栏（小标题形态，variant 按场景选择）
- 内容边距：左右 **28dp**（默认）；卡片形列表作为内容时由卡片自带 padding（12dp）替代；图片 / 列表首项距标题栏 **12dp**

### 抽屉 DrawerWindow

适用设备：手机、折叠屏外屏。

| 维度 | 值 |
|------|-----|
| 宽度 | **392dp** |
| 高度（高 / 中默认 / 低收起） | **819 / 508 / 112dp**，三档，不支持无极悬停 |

- 位置：贴屏幕底部
- 结构：❶ 滑动把手（顶部）+ ❷ 标题栏（左侧可选关闭按钮，不支持大字标题，其余同全屏标题栏）+ ❸ 内容区（列表 / 宫格 / 底部按钮）
- 内容边距：左右 **12dp**；卡片形列表作为内容时由卡片自带 padding 替代
- 类型（决定是否绘制遮罩）：

| 类型 | 遮罩 | 背景交互 |
|------|------|---------|
| 模态抽屉 | 有（`遮罩色/mask` 20%） | 不可 |
| 非模态抽屉 | 无 | 可 |

### 弹窗 Dialog

适用设备：全设备通用。

| 维度 | 值 |
|------|-----|
| 宽度 | 固定 **368dp** |
| 最大高度 | 屏幕高度 × **80%**（手机上下分屏 / 横屏不受此限制） |

- 横屏下无法正常显示时可改为左右布局（MIUIX 支持）
- 位置：左右居中（全设备通用）；上下位置按设备：

| 设备 / 屏态 | 纵向位置 |
|-----------|---------|
| 手机（竖 / 横 / 上下分屏） | 居底，距小白条 / 虚拟键 **16dp** |
| 折叠屏外屏（竖 / 横） | 居底，距小白条 / 虚拟键 **16dp** |
| 折叠屏内屏（竖 / 横） | 上下居中 |
| Pad（竖 / 横） | 上下居中 |

- 结构：弹窗容器 + 标题栏（小标题；左 `×` 关闭 / 右 `✓` 确认，可选）+ 内容区
- 内容边距：左右 **12dp**

### 菜单 Menu

适用设备：全设备通用，无跨设备形态切换（始终为锚点式浮层，依附于触发元素）。

| 维度 | 值 |
|------|-----|
| 宽度 | 最小 **200dp** / 最大 **288dp**（按内容自适应） |
| 容量上限 | 单行项最多 **8** 项 + 分割线最多 **3** 条，超出进入二级菜单 |

位置（锚点相对 —— 位置计算必需）：

| 触发场景 | 顶部偏移 | 右侧偏移 |
|---------|---------|---------|
| 从状态栏触发（导航栏 `⋮` 等） | 距状态栏 **6dp** | 距屏幕右 **12dp** |
| 从侧边栏 / 浮层容器内触发 | 距容器顶部 **12dp** | 距容器右 **12dp** |

结构：

| variant | 用途 |
|---------|------|
| `Menu-ComponentSet_01` | 默认菜单 |
| `Menu-ComponentSet_02` | 分组 / 选择（单选 `✓` 或多选） |
| `Menu-ComponentSet_03` | 分组 / 进入二级菜单（`›`） |

项内部元素：图标 + 主标题（推荐统一加图标，也可仅主标题）；可选次要描述（最多 2 行）；选中态主标题 + `✓` 均为主色。
