# LC / NC 布局规则（双栏分栏）

本文档定义 LC 和 NC 双栏布局的结构规则。仅定义槽位、栏宽、间距，不做组件选择。

组件选择由 `app-variant-map-{appName}.md` 负责。

## 适用范围

LC / NC 适用于 **Fold 内屏**（横屏 / 竖屏）和 **Pad**（横屏 / 竖屏）。

| 布局 | 左栏角色 | 适用应用类型 |
|------|---------|------------|
| **LC** | L 栏（列表） | 无底部 Tab 导航的"列表 + 详情"应用（如设置、短信、联系人详情） |
| **NC** | N 栏（导航） | 有底部 Tab 导航但无需列表栏的应用 |

## 栏宽

具体数值见 `device-dimensions.md`，以下为速查。

### Fold 内屏

| 分栏模式 | 左栏宽度 | 右栏宽度 |
|---------|---------|---------|
| 横屏 分栏_常规（0.4:0.6） | 353dp | 535dp |
| 横屏 分栏_特殊（0.5:0.5） | 444dp | 444dp |
| 竖屏 分栏_常规（0.45:0.55） | 283dp | 345dp |

### Pad LC

| 方向 | L 栏宽度 | C 栏宽度 | L 栏 padding | C 栏 padding |
|------|---------|---------|-------------|-------------|
| 横屏 | 440dp | 982dp | 20dp | 56dp |
| 竖屏 | 440dp | 509dp | 20dp | 20dp |

### Pad NC

| 方向 | N 栏宽度 | C 栏宽度 | N 栏 padding | C 栏 padding |
|------|---------|---------|-------------|-------------|
| 横屏 | 272dp | 1150dp | 12dp | 56+25dp（超过 1100 按 1100 的 padding + 剩余宽度） |
| 竖屏 | 272dp | 677dp | 12dp | 28dp |

## 双栏槽位结构

### LC 模式

```
┌──────────────────┬──────────────────────────┐
│     L 栏          │         C 栏              │
│                  │                          │
│ [标题栏槽]        │ [标题栏槽]                │
│ [搜索栏槽]        │                          │
│ [标签栏槽]        │ [正文区]                  │
│                  │                          │
│ [列表区]          │                          │
│                  │ [底部操作区槽]             │
└──────────────────┴──────────────────────────┘
```

### NC 模式

```
┌─────────┬──────────────────────────────────┐
│  N 栏   │              C 栏                 │
│         │                                  │
│ [导航槽] │ [标题栏槽]                        │
│         │                                  │
│         │ [正文区]                           │
│         │                                  │
│         │ [底部操作区槽]                      │
└─────────┴──────────────────────────────────┘
```

## LC — L 栏（列表栏）

| 槽位 | 说明 |
|------|------|
| 标题栏槽 | 列表栏标题栏。具体 variantId 查 `app-variant-map` |
| 搜索栏槽 | 搜索栏。具体 variantId 查 `app-variant-map` |
| 标签栏槽 | 分段控件 / 选项卡。具体 variantId 查 `app-variant-map` |
| 列表区 | 列表内容填充剩余视窗 |

规则：
- 移除手机端不需要的元素（底部提示器等）
- 列表选中项与 C 栏详情语义一致

## NC — N 栏（导航栏）

| 槽位 | 说明 |
|------|------|
| 导航槽 | 侧边导航栏组件。具体 variantId 查 `app-variant-map` |

规则：
- 手机端悬浮底部导航栏转为侧边导航栏，原悬浮底部导航栏移除
- 展开/收起、侧边/顶部导航切换规则同 `layout-nlc.md` N 栏

## C 栏（内容区，LC / NC 通用）

| 槽位 | 说明 |
|------|------|
| 标题栏槽 | 内容区标题栏。具体 variantId 查 `app-variant-map` |
| 正文区 | 正文内容，通过视窗裁剪表达可视区域 |
| 底部操作区槽 | 固定底部操作区 |

规则：
- 删除移动端状态栏、底部手势条、键盘弹层

## 栏间分割线

- 分割线为右侧栏 inside stroke 1px
- 具体见 `device-dimensions.md`

## Fold 内屏特殊处理

- Q18 Fold 左右分栏 + 悬浮底部导航栏并存时：底导航与 fab 分开展示，fab 置于最右侧，底导航控制在左侧栏宽度以内（详见 `device-dimensions.md`）

## 语义一致性

- 列表选中项（LC）或导航选中项（NC）与内容区详情语义必须一致
- 空状态：列表为空时，内容区显示空状态占位
