# NLC 布局规则（Navigation-List-Content 三栏）

本文档定义 NLC 三栏布局的结构规则。仅定义槽位、栏宽、间距，不做组件选择。

组件选择由 `app-variant-map-{appName}.md` 负责。

## 适用范围

NLC 布局仅适用于 **Pad**（横屏 / 竖屏），不适用于 Fold。

适配对象：手机端有悬浮底部导航栏（Bottom Tab Bar）的应用——转为 NLC 三栏后，手机端悬浮底部导航栏转为侧边导航栏（N 栏），原悬浮底部导航栏移除。

## 栏宽

具体数值见 `device-dimensions.md`，以下为速查。

| 方向 | N 栏 | L 栏 | C 栏 |
|------|------|------|------|
| Pad 横屏 展开 | 272dp | 428dp | 722dp |
| Pad 横屏 收起 | 88dp | 428dp | 906dp |
| Pad 竖屏 展开 | 272dp | 304dp | 373dp |
| Pad 竖屏 收起 | 88dp | 387dp | 474dp |

## 三栏槽位结构

```
┌─────────┬──────────────────┬──────────────────────────┐
│  N 栏   │     L 栏          │         C 栏              │
│         │                  │                          │
│ [导航槽] │ [标题栏槽]        │ [标题栏槽]                │
│         │ [搜索栏槽]        │                          │
│         │ [标签栏槽]        │ [正文区]                  │
│         │                  │                          │
│         │ [列表区]          │                          │
│         │                  │ [底部操作区槽]             │
└─────────┴──────────────────┴──────────────────────────┘
```

### N 栏（导航栏）

| 槽位 | 说明 |
|------|------|
| 导航槽 | 侧边导航栏组件。具体 variantId 查 `app-variant-map` 的 `导航` uiElement |
| 标题栏槽 | 侧边栏标题栏。具体 variantId 查 `app-variant-map` 的 `标题栏` uiElement（N 栏部分） |

N 栏规则：
- 手机端悬浮底部导航栏转为侧边导航栏，导航项数量和顺序保持一致
- 展开态：图标 + 文字标签
- 收起态：仅图标
- 默认 Pad 横屏/竖屏均展开态
- 悬浮侧边栏显示时，N 栏内部左侧产生 6dp padding

### L 栏（列表栏）

| 槽位 | 说明 |
|------|------|
| 标题栏槽 | 列表栏标题栏。具体 variantId 查 `app-variant-map`（L 栏部分） |
| 搜索栏槽 | 搜索栏。具体 variantId 查 `app-variant-map` 的 `搜索` uiElement |
| 标签栏槽 | 分段控件 / 选项卡。具体 variantId 查 `app-variant-map` |
| 列表区 | 列表内容填充剩余视窗 |

L 栏规则：
- 移除手机端悬浮底部导航栏（已转为 N 栏）
- 列表选中项与 C 栏详情语义一致

### C 栏（内容区）

| 槽位 | 说明 |
|------|------|
| 标题栏槽 | 内容区标题栏。具体 variantId 查 `app-variant-map`（C 栏部分） |
| 正文区 | 正文内容，通过视窗裁剪表达可视区域 |
| 底部操作区槽 | 固定底部操作区（如 AI 输入框） |

C 栏规则：
- 删除移动端状态栏、底部手势条、键盘弹层
- 不保留完整长页，通过视窗裁剪

## 栏间分割线

- 分割线为右侧栏 inside stroke 1px
- 具体见 `device-dimensions.md`

## 横竖屏旋转

见 `device-dimensions.md` 横竖屏旋转规则章节。

## 语义一致性

- 导航栏选中项、列表栏内容、内容区详情三者语义必须一致
- 空状态：列表为空时，内容区显示空状态占位
